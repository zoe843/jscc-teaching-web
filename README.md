# Transformer × JSCC 学习网页

在线阅读：https://zoe843.github.io/jscc-teaching-web/

从 CNN-JSCC 到 Transformer-JSCC，包含功率归一化、信道模型、图像切块、SNR 条件调节和实验设计。支持手机阅读、公式显示、交互演示与 Python 示例下载。

网页演示用于学习局部机制，不代表完整模型训练或论文复现结果。Python 示例需要下载到有相应依赖的电脑上运行。

## 本地阅读

下载仓库后双击 `index.html`，或启动静态 HTTP 服务。公式字体和脚本均包含在仓库中。

## 发布

GitHub Pages 从 `main` 分支根目录发布。修改网页后提交并推送到 `main`，等待 Pages 部署完成即可更新同一个网址。
